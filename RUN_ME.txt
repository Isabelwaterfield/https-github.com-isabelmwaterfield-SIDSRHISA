IMPORTANT (Windows Application Control)
---------------------------------------
UseAppHost is false so Windows does not need SIDSRH.Api.exe.
Always run via the DLL:

  cd C:\SIDSRH_PHASE5_FINAL\SIDSRH.Api
  Get-ChildItem -Recurse | Unblock-File
  Remove-Item sidsrh_offline.db -ErrorAction SilentlyContinue
  dotnet restore
  dotnet build
  dotnet run --no-launch-profile --urls http://localhost:5080

Open: http://localhost:5080

If DLL is still blocked (0x800711C7), ask IT to allow the folder, or run on a PC without WDAC.
